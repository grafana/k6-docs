# Data file preview

The data file preview lets you inspect a CSV or JSON file that you imported into k6 Studio, before using it in a [parameterization rule](https://grafana.com/docs/k6-studio/components/generator/#parameterization-rule).

Refer to [Data files](https://grafana.com/docs/k6-studio/components/generator/#data-files) for the supported file formats and how to import a data file.

## Preview a data file

Click a file under **Data files** in the sidebar to open its preview. The preview shows:

- The number of rows shown out of the total number of rows in the file.
- A table with a column for each property in the file.

If the file has more rows than what's shown in the preview, open the file in its default application to see the full content.

## Manage a data file

From the top-right of the data file preview, you can:

- Click **Open in default app** to open the file in your computer's default application for its file type.
- Click the menu icon to **Open containing folder**, or to move the file to the Trash.
